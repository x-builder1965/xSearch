# xSearch -プレイリスト検索-

`xSearch` は、ローカルのメディアフォルダー（`.amppl` プレイリスト）をスキャン・管理し、外部APIと連携してアニメやメディアのメタデータを自動取得・一覧表示、さらにプレイリストの統合保存が行える Electron 製のデスクトップアプリケーションです。

---

## 🌟 主な機能

- **フォルダー・プレイリストスキャン**: 指定したディレクトリ内のサブフォルダーや `.amppl` ファイルを再帰的にスキャンし、シリーズ名やタイトル情報を自動解析します。
- **外部API連携による自動メタデータ取得**:
  - **AniList API**: シリーズ名からジャンル（英語）を自動取得し、日本語に翻訳して表示。
  - **しょぼいカレンダーAPI**: タイトル名から作品ID（TID）を自動検索・付与。
- **高速再検索 (Sync)**: ファイルやフォルダの追加・変更・削除を効率的に同期し、常に最新のデータを維持します。
- **チェックボックスによる選択保存**: 画面上で保存対象を選択（個別選択 / 一括全選択）し、チェックされた項目の `.amppl` ファイルを統合して新しいプレイリストファイル（デフォルト: `xSearch.amppl`）として出力・保存。
- **ライト / ダークテーマ切替**: 目の負担を軽減するダークモードとライトモードの即時切り替えに対応。
- **ヘルプ & 修正履歴表示**: アプリタイトルやバージョンをクリックするだけで、詳細な操作マニュアルや修正履歴画面へ簡単にアクセス可能。

---

## 🛠️ 技術スタック

- **Framework**: Electron (Node.js)
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
- **APIs**:
  - [AniList GraphQL API](https://anilist.gitbook.io/anilist-apiv2-docs/)
  - [しょぼいカレンダー API](https://cal.syoboi.jp/)

---

## 💻 画面構成と操作方法

1. **📁 フォルダ選択ボタン**: 検索・管理を行いたいローカルのルートディレクトリを選択します。
2. **🔎 高速再検索ボタン**: ディレクトリ内の変更差分を素早くチェックし、リストを更新します。
3. **💾 プレイリスト保存ボタン**: チェックが入った項目のプレイリストを1つに統合して `.amppl` ファイルとして保存します。
4. **☀️ / 🌙 テーマ切替ボタン**: 画面のカラーテーマを切り替えます。
5. **タイトル / バージョンクリック**: それぞれクリックすると「ヘルプ」または「修正履歴」画面に切り替わります。
